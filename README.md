# 메신저 접속 상태(ON→OFF) 감지·기록 프로그램

"서울특별시 메신저"에서 **특정 사람이 ON(접속) 상태였다가 OFF(오프라인)로 바뀌는 순간**을
자동으로 감지해서 시간을 CSV 파일에 기록합니다.

## 왜 이런 방식인가?

이 메신저는 외부에서 접속 상태를 가져올 수 있는 공개 API가 없습니다.
그래서 가장 현실적인 방법은 **화면에 보이는 상태 아이콘의 색을 읽는 것**입니다.

| 아이콘 | 색 | 의미 |
|--------|------|------|
| 🔴 ON  | 빨강 | 접속 중 |
| 🔵 시계 | 파랑 | 자리비움(AWAY) |
| ⚫ OFF | 회색 | 오프라인 |

이 색이 **빨강 → 회색**으로 바뀌면 "오프라인 전환"으로 보고 시간을 기록합니다.

## 설치

```bash
pip install -r requirements.txt
```

## 사용법

### 1) 감시할 사람 등록 (좌표 찍기)

메신저 목록 창을 **항상 같은 위치**에 띄워 둔 상태에서:

```bash
python status_monitor.py calibrate
```

안내에 따라 이름을 입력하고, 그 사람의 **상태 아이콘(동그라미) 위에 마우스를 올린 뒤**
Enter를 누르면 좌표가 등록됩니다. 여러 명 등록 가능. 끝내려면 이름을 빈칸으로 두고 Enter.

### 2) 감시 시작

```bash
python status_monitor.py run
```

`Ctrl+C`로 종료합니다. 감시 중에는 메신저 창이 가려지거나 위치가 바뀌면 안 됩니다.

## 결과 파일

`status_log.csv` 에 아래와 같이 기록됩니다 (엑셀에서 바로 열림):

```
시각,이름,이벤트,RGB
2026-06-29 14:03:21,심재호,ON->OFF (오프라인 전환),120,120,120
```

## 설정 (`config.json`)

`calibrate`를 실행하면 자동 생성됩니다. 직접 수정도 가능:

```json
{
  "poll_interval_sec": 5,     // 확인 주기(초)
  "sample_radius": 3,         // 아이콘 색 평균낼 범위(px)
  "log_file": "status_log.csv",
  "targets": [
    { "name": "심재호", "x": 27, "y": 423 }
  ]
}
```

## 주의 / 한계

- 메신저 창의 **위치·크기·테마**가 바뀌면 좌표를 다시 등록(`calibrate`)해야 합니다.
- 화면 잠금/절전 시에는 감지가 멈춥니다.
- 색만 보므로, 같은 사람을 목록에서 스크롤로 안 보이게 하면 잘못 읽을 수 있습니다.
